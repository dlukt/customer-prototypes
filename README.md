## GitHub Pages

Für eine Veröffentlichung über GitHub Pages:
1. Repository **Settings → Pages** öffnen.
2. **Build and deployment → Source: Deploy from a branch** wählen.
3. **Branch: main**, Verzeichnis **/(root)** auswählen und speichern.

Danach ist die Projektübersicht unter `https://dlukt.github.io/customer-prototypes/` erreichbar und der bbeCoaching-Prototyp unter `https://dlukt.github.io/customer-prototypes/bbecoaching/`.

Die Entwürfe sind nicht vom jeweiligen Kunden beauftragt oder freigegeben. Keine vertraulichen Unterlagen, Zugangsdaten oder personenbezogenen Kundendaten ins Repository hochladen. GitHub Pages ist öffentlich.
